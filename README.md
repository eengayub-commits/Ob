# 🏭 موقع مصنع برج القمة للأعمال المعدنية (QTG)

موقع إلكتروني متكامل (عربي، RTL، متجاوب مع الجوال) لمصنع ألمنيوم وواجهات زجاجية،
مع **نظام طلبات كامل** يرسل الطلب مباشرة إلى واتساب المصنع وبريده الإلكتروني.

> 📋 **ابدأ من هنا:** ملف [`REQUIREMENTS.md`](REQUIREMENTS.md) يحتوي قائمة كل ما تحتاج توفيره (صور، أرقام، أسعار).

---

## ✨ ما الذي يحتويه الموقع؟

| الصفحة | الوصف |
|---|---|
| `index.html` | الرئيسية: غلاف، أقسام، منتجات مميزة، خطوات العمل، خدمات، معرض، آراء، أسئلة |
| `products.html` | كل المنتجات مع **بحث** و**تصفية حسب القسم** |
| `product.html` | صفحة المنتج: صور، مواصفات، اختيار المقاس واللون ونوع الزجاج + إضافة للطلب |
| `order.html` | **سلة الطلب** + نموذج بيانات العميل + إرسال عبر واتساب أو بريد |
| `services.html` | الخدمات ومراحل التنفيذ (للأفراد وللمقاولين) |
| `projects.html` | معرض الأعمال مع عارض صور (Lightbox) وتصفية |
| `about.html` | من نحن، الرؤية والرسالة، إمكانيات المصنع، الاعتمادات |
| `contact.html` | بيانات التواصل، الخريطة، نموذج مراسلة |
| `faq.html` | الأسئلة الشائعة (مع بيانات منظّمة تظهر في جوجل) |
| `thanks.html` | صفحة تأكيد الطلب برقم مرجعي |
| `privacy.html` / `terms.html` | سياسة الخصوصية والشروط والأحكام |
| `404.html` | صفحة الخطأ |

**مزايا تقنية:**
- 🛒 سلة طلبات تُحفظ في متصفح الزائر (لا تضيع عند تحديث الصفحة).
- 🧮 حساب المساحة تلقائياً حسب المقاس (م² / متر طولي / قطعة) لإرسالها مع الطلب.
- 🙈 الأسعار **مخفية حالياً** (وضع «طلب عرض سعر») — تُظهر بتغيير `showPrices` إلى `true`.
- 📱 إرسال الطلب كرسالة واتساب منسّقة بضغطة واحدة.
- ✉️ إرسال نسخة إلى البريد الإلكتروني (عبر Web3Forms أو Formspree).
- 🔍 تهيئة كاملة لمحركات البحث: وسوم Meta، Open Graph، Sitemap، Robots، JSON-LD.
- ♿ دعم إمكانية الوصول: تنقّل بلوحة المفاتيح، روابط تخطٍ، نصوص بديلة.
- ⚡ بدون أي مكتبات خارجية — الموقع سريع جداً ويعمل على أي استضافة.
- 🖼️ أي صورة ناقصة تُستبدل تلقائياً بصورة مؤقتة، فلا يتعطل التصميم.

## 🚀 التشغيل محلياً

```bash
# أي خادم بسيط يكفي
python3 -m http.server 8000
# ثم افتح: http://localhost:8000
```

> ⚠️ لا تفتح الملفات بالنقر المزدوج مباشرة (بروتوكول `file://`) — بعض المزايا تحتاج خادماً.

## ⚙️ التعديل — 3 ملفات فقط

### 1) `assets/js/config.js` — بيانات المصنع
أرقام الهاتف والواتساب، البريد، العنوان، الخريطة، السجل التجاري، حسابات التواصل، وإعدادات الطلبات.

```js
phone: "+966500000000",
whatsapp: "966500000000",   // بدون + وبدون صفر
email: "info@burjalqimma.com",
order: {
  web3formsKey: "",   // ضع مفتاح Web3Forms هنا ليصلك الطلب بالبريد
  showPrices: false   // الأسعار مخفية — اجعلها true لإظهارها في كل الموقع
}
```

### 2) `assets/js/data.js` — المنتجات والمحتوى
المنتجات، الأقسام، الأسعار، المواصفات، الخدمات، المشاريع، الأسئلة الشائعة، آراء العملاء.

```js
{
  id: "door-sliding",            // معرّف فريد (يُستخدم في الرابط)
  cat: "doors",                  // القسم
  name: "باب ألمنيوم سحاب",
  unit: "م²",                    // "م²" أو "م.ط" أو "قطعة"
  price: 450,                    // ضع null ليظهر "السعر حسب الطلب"
  img: ["assets/img/products/door-sliding-1.jpg"],
  specs: [{ k: "الزجاج", v: "دبل جلاس 6+12+6" }]
}
```

### 3) `assets/css/styles.css` — الألوان
غيّر المتغيرات في أعلى الملف فقط:

```css
--navy:#0d1b2a;   /* اللون الأساسي */
--gold:#c9a227;   /* لون التمييز */
```

## 📧 ربط استقبال الطلبات بالبريد (5 دقائق)

1. ادخل [web3forms.com](https://web3forms.com) وأدخل بريدك → يصلك **Access Key**.
2. ضعه في `assets/js/config.js`:
   ```js
   order: { web3formsKey: "ضع-المفتاح-هنا" }
   ```
3. جرّب إرسال طلب — ستصلك رسالة بكامل تفاصيل الطلب.

> بدون هذا المفتاح يبقى **زر الواتساب يعمل بشكل طبيعي**، والموقع ينبّه إلى ذلك بدل أن يفشل صامتاً.

## 🌍 النشر

### GitHub Pages (مجاني)
Settings ← Pages ← Source: `Deploy from a branch` ← اختر الفرع و `/root` ← Save.

### Netlify (مجاني، ويدعم النطاق الخاص)
اسحب مجلد المشروع إلى [app.netlify.com/drop](https://app.netlify.com/drop).

### بعد النشر
1. غيّر `siteUrl` في `config.js` إلى رابط موقعك.
2. استبدل `https://example.com` في `sitemap.xml` و`robots.txt` وروابط `canonical` داخل صفحات HTML.
3. أضف الموقع إلى [Google Search Console](https://search.google.com/search-console) وأرسل `sitemap.xml`.

├── assets/
│   ├── css/styles.css             # كل التنسيقات
│   ├── js/

├── robots.txt · sitemap.xml
├── REQUIREMENTS.md                # 📋 قائمة ما تحتاج توفيره

> **ملاحظة للمطوّر:** الهيدر والفوتر مكرران داخل كل صفحة HTML (لضمان أفضل أرشفة في جوجل).
> عند تعديل رابط في القائمة، عدّله في كل الصفحات — أو استخدم بحث واستبدال شامل.

## 🔒 ملاحظات أمان ومصداقية

- لا يحفظ الموقع أي بيانات على خادم؛ سلة الطلب تُخزَّن في متصفح الزائر فقط، ولا تُرسل إلا عند ضغط زر الإرسال.
- النموذج يحوي حقل فخّ (Honeypot) لصدّ الرسائل المزعجة الآلية.
- **قبل النشر:** استبدل الأرقام التوضيحية (عدد المشاريع، سنوات الخبرة) وآراء العملاء ببيانات حقيقية.
