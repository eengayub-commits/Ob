# 📸 مجلد الصور

معظم الصور الحالية **مستخرجة من الملف التعريفي الرسمي للمصنع**.
لاستبدال أي صورة: ضع صورتك بنفس الاسم في نفس المجلد — لا حاجة لتعديل أي كود.

> أي صورة ناقصة يعرض الموقع بدلاً منها صورة مؤقتة تلقائياً، فلا يتعطل التصميم.

## 1) صور أساسية — `assets/img/`

| الملف | أين يظهر | المقاس |
|---|---|---|
| `hero.jpg` | غلاف الصفحة الرئيسية | 1920×1080 |
| `factory.jpg` | صفحة «من نحن» | 1200×900 |

## 2) صور المنتجات — `assets/img/products/` (1000×750)

| الملف | المنتج |
|---|---|
| `facade-curtain-wall.jpg` | واجهات ألمنيوم ثابتة — كيرتن وول |
| `facade-structure.jpg` | واجهات ألمنيوم ثابتة — استركتشر |
| `windows-aluminum.jpg` | نوافذ ألمنيوم (سحاب/ثابت/مفصلات/قلاب) |
| `skylight.jpg` | القبب الزجاجية والسكاي لايت |
| `door-folding.jpg` | أبواب فولدينج |
| `door-aluminum.jpg` | أبواب ألمنيوم |
| `frameless.jpg` + `partitions.jpg` | الفريملس بجميع أنواعه والقواطع |
| `mirrors.jpg` | المرايا بجميع أنواعها |

## 3) صور المشاريع — `assets/img/projects/` (1200×900)

`project-1.jpg` … `project-10.jpg` — عناوينها تُعدَّل من `assets/js/data.js` في قسم `PROJECTS`.

## 4) الهوية — `assets/img/brand/`

| الملف | الوصف |
|---|---|
| `logo.png` | الشعار الكامل بخلفية شفافة |
| `logo-mark.png` | رمز الشعار (الهيدر والفوتر) |
| `favicon.png` · `apple-touch-icon.png` · `icon-192.png` · `icon-512.png` | أيقونات المتصفح والتطبيق |
| `og-image.jpg` | صورة المشاركة في واتساب وتويتر (1200×630) |
| `whatsapp-qr.png` | باركود الواتساب |
| `partners.jpg` | لوحة شركاء النجاح والموردين المعتمدين |

## 5) اختياري
- `assets/img/certificates/` — صور الشهادات والتراخيص إن رغبت بعرضها.
- `assets/img/team/` — صور فريق العمل.

---

### نصائح
- صوّر بإضاءة نهارية وزاوية ثابتة، وتجنّب الصور المائلة.
- خفّف حجم كل صورة إلى أقل من **300 كيلوبايت** عبر [squoosh.app](https://squoosh.app) أو [tinypng.com](https://tinypng.com).
- استخدم `.jpg` للصور الفوتوغرافية و`.png`/`.svg` للشعارات.
