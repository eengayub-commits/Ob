# 📸 مجلد الصور — ضع صورك هنا بنفس الأسماء

> أي صورة ناقصة يعرض الموقع بدلاً منها صورة مؤقتة تلقائياً، فلا يتعطل شيء.
> يمكنك إضافة الصور تدريجياً.

## 1) صور أساسية (في هذا المجلد مباشرة `assets/img/`)

| اسم الملف | الوصف | المقاس المقترح |

| `hero.jpg` | صورة الغلاف في أعلى الصفحة الرئيسية (واجهة زجاجية أو داخل المصنع) | 1920×1080 |

## 4) الهوية → `assets/img/brand/`

| اسم الملف | الوصف | المقاس |

| `logo.svg` أو `logo.png` | شعار المصنع (يفضّل بخلفية شفافة) | 512×512 |

## 5) الشهادات (اختياري) → `assets/img/certificates/`

## 6) فريق العمل (اختياري) → `assets/img/team/`
صور المدير والمهندسين إن رغبت بإضافة قسم «فريقنا».

---

### نصائح تجعل الصور احترافية
- صوّر بإضاءة نهارية وزاوية ثابتة، وتجنّب الصور المائلة.
- خفّف حجم كل صورة إلى أقل من **300 كيلوبايت** عبر [squoosh.app](https://squoosh.app) أو [tinypng.com](https://tinypng.com) — هذا يسرّع الموقع كثيراً.
- استخدم صيغة `.jpg` للصور الفوتوغرافية و`.png`/`.svg` للشعارات.
- لا تستخدم صوراً من الإنترنت لمشاريع ليست لك (حقوق ملكية + يضر بالمصداقية).
