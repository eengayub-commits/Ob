# خطة إنشاء موقع إلكتروني لمندوب/موزّع زين — السوق السعودي

**النطاق:** موقع تعريفي يستقبل طلبات العملاء (شرائح، باقات، أجهزة، تحويل رقم) ويحوّلها إلى واتساب المندوب لإتمامها عبر القنوات الرسمية.
**آخر تحديث:** 2026-09
**تنبيه:** الأرقام تقديرية وسوقية، والمتطلبات النظامية تتغيّر. تحقّق من المصدر الرسمي (وزارة التجارة، هيئة الاتصالات والفضاء والتقنية CST، هيئة الزكاة والضريبة والجمارك ZATCA، سدايا SDAIA) قبل الالتزام المالي.

---

## 0) قبل أي سطر برمجي: ثلاث نقاط تُسقط المشروع إن أُهملت

### 0.1 لا تفعيل شرائح عبر الموقع
تفعيل الشريحة في المملكة يتطلب تحقق هوية بيومتري (بصمة) عبر نقطة بيع أو مندوب معتمد. الموقع **قناة استقطاب طلبات فقط**:
`زائر → نموذج طلب → واتساب → موعد/زيارة → تفعيل رسمي عبر نظام زين`.
أي وعد بـ"تفعيل أونلاين فوري" مخالفة تنظيمية وتعرّض عقد الوكالة للإلغاء.

### 0.2 استخدام اسم وشعار "زين"
الشعار والاسم علامة تجارية مسجّلة. استخدامها بلا إذن خطي من زين السعودية (إدارة قنوات التوزيع / التسويق) يعرّضك لإنذار قانوني وإيقاف النطاق.
- **المسار الآمن:** اسم تجاري مستقل (مثال: "اتصالات الرياض للخدمات") + عبارة واضحة: *"موزّع معتمد — لسنا الموقع الرسمي لشركة زين"* في الهيدر والفوتر.
- **المسار الأفضل:** خطاب موافقة من زين على استخدام الشعار وهوية "وكيل معتمد"، مع الالتزام بدليل العلامة (Brand Guidelines).
- لا تشترِ نطاقاً يحتوي كلمة `zain` (مثل `zain-riyadh.com`) — هذا أسرع طريق لمطالبة قانونية.

### 0.3 لا تجمع صور الهوية عبر الموقع
نظام حماية البيانات الشخصية (PDPL) ونظام مكافحة الجرائم المعلوماتية. اجمع فقط: **الاسم، رقم الجوال، المدينة، نوع الطلب**. صور الهوية والبصمة تتم وجهاً لوجه فقط.

## 2) الخطوات الفنية

### المرحلة أ — الأساس (أسبوع 1)
1. **النطاق:**
   - `.com.sa` عبر SaudiNIC — يتطلب سجل تجاري، مصداقية محلية أعلى. ~100–200 ر.س/سنة.
   - `.sa` للأفراد، أو `.com` عام (~50–80 ر.س/سنة).
2. **الاستضافة/النشر:**
   - **موصى به للبداية:** Cloudflare Pages أو Vercel أو Netlify — الخطة المجانية تكفي تماماً لموقع تعريفي، مع CDN وشهادة SSL مجانية.
   - **بديل محلي** (إن أردت تخزين بيانات العملاء داخل المملكة توافقاً مع PDPL): استضافة سعودية (stc cloud / سلام / مزودون محليون) ~300–900 ر.س/سنة.
3. **شهادة SSL:** مجانية (Let's Encrypt / Cloudflare). إلزامية — لا تُطلق موقعاً بـ HTTP.
4. **بريد احترافي:** `info@yourdomain.com.sa` عبر Google Workspace (~22 ر.س/مستخدم/شهر) أو Zoho Mail (خطة مجانية محدودة).

### المرحلة ب — بناء الموقع (أسبوع 1–3)
اختر مساراً واحداً:

| المسار | الأداة | متى تختاره | التكلفة |
|--------|--------|------------|---------|
| **أ. منشئ مواقع** | Framer / Webflow / Wix | لا خبرة تقنية، تريد تعديل المحتوى بنفسك | 0–1,500 ر.س/سنة اشتراك |
| **ب. ووردبريس** | WordPress + Elementor + قالب عربي | تريد مدونة ومحتوى كثير وتحكماً واسعاً | قالب 250–400 ر.س + استضافة 400–900/سنة |
| **ج. كود مخصص** | Astro أو Next.js على Cloudflare/Vercel | تريد أسرع أداء وأرخص تشغيل وتحكماً كاملاً | 0 ر.س استضافة + تكلفة المطوّر |

**التوصية:** للمندوب الفرد، المسار (ج) أو (أ). الموقع صغير (5 صفحات) والسرعة على شبكة الجوال هي عامل التحويل الأول.

**الصفحات المطلوبة (الحد الأدنى):**
- الرئيسية: عرض واضح + زر واتساب ثابت + نموذج طلب.
- الباقات/العروض: جداول مقارنة، مع تنويه "الأسعار حسب تعرفة زين المعلنة وقابلة للتغيير".
- الأجهزة/الإكسسوارات (إن وُجدت).
- من نحن + معلومات التوثيق (السجل، العنوان، شارة معروف).
- تواصل معنا + الخصوصية + الشروط.

### المرحلة ج — قناة الطلبات (الجزء الأهم)
**المستوى 1 — مجاني، ابدأ هنا:**
- زر عائم `wa.me/9665XXXXXXXX?text=...` برسالة معبّأة مسبقاً تحدد نوع الطلب ومصدره.
- استخدم نصاً مختلفاً لكل صفحة → تعرف من أين جاء العميل بلا أدوات تحليل.

**المستوى 2 — نموذج مُهيكل (موصى به بعد أول 50 طلب):**
- نموذج → يُخزّن في Google Sheets أو Airtable (عبر Apps Script / Formspree / n8n) → يفتح واتساب تلقائياً + يرسل لك إشعاراً.
- تكلفة: 0–150 ر.س/شهر.

**المستوى 3 — واتساب للأعمال API:**
- عبر Meta Cloud API مباشرة، أو مزوّد (Unifonic محلياً / Wati / 360dialog).
- يتيح: ردوداً آلية، قوالب رسائل، فريق عمل على رقم واحد، تتبع حالة الطلب.
- تكلفة: اشتراك المزود ~150–500 ر.س/شهر + رسوم رسائل لكل محادثة مبدوءة من عملك.
- **لا تحتاجه إلا عند تجاوز ~10 طلبات يومياً.**

### المرحلة د — القياس والنمو
- **Google Business Profile** (خرائط جوجل): مجاني، وهو غالباً **أقوى مصدر طلبات للمندوب المحلي** — أهم من الموقع نفسه. فعّله يوم 1.
- GA4 + Google Tag Manager: مجاني. اضبط حدث `whatsapp_click` و `form_submit` كتحويلات.
- Meta Pixel / TikTok Pixel إن أعلنت هناك.
- سيو محلي: عنوان الصفحة وأوصافها تحمل "المدينة + الخدمة" (مثال: "شرائح وباقات — توصيل وتفعيل في جدة").

### المرحلة هـ — الأمان والامتثال التقني
- Cloudflare Turnstile أو reCAPTCHA على النموذج (مجاني) لمنع السبام.
- تحديد معدل الإرسال (Rate limiting).
- عدم تخزين أي بيانات حساسة؛ الاحتفاظ ببيانات الطلب لمدة محدودة ثم حذفها.
- خانة موافقة صريحة: *"أوافق على التواصل معي عبر واتساب/الهاتف بخصوص طلبي"* — مطلب PDPL.
- نسخ احتياطي دوري.

## 3) الخطوات المالية

### 3.1 التكلفة التأسيسية (مرة واحدة)

| البند | ذاتي (DIY) | مستقل محترف | وكالة |
|-------|-----------|-------------|-------|
| تصميم وبناء الموقع | 0 | 2,500–8,000 | 15,000–40,000 |
| هوية بصرية وشعار | 0–300 | 800–2,500 | 3,000–8,000 |
| محتوى وصور | 0–500 | 500–1,500 | 2,000–5,000 |
| صياغة قانونية (خصوصية/شروط) | 0 | 0–1,500 | مشمول |
| **الإجمالي التقديري** | **0–800 ر.س** | **4,000–13,500 ر.س** | **20,000–53,000 ر.س** |

### 3.2 التكلفة التشغيلية السنوية

| البند | تقدير سنوي |
|-------|-----------|
| النطاق | 60–200 |
| الاستضافة | 0–900 |
| بريد احترافي | 0–800 |
| اشتراك منشئ المواقع (إن استُخدم) | 0–1,500 |
| أداة نماذج/أتمتة | 0–1,800 |
| واتساب API (اختياري لاحقاً) | 0–6,000 |
| صيانة وتحديثات | 0–3,000 |
| **الإجمالي** | **60–14,200 ر.س** |

> **الحد الأدنى الواقعي للانطلاق: 500–900 ريال للسنة الأولى** إذا بنيت الموقع بنفسك على استضافة مجانية.

### 3.3 ميزانية التسويق (البند الأكبر فعلياً)
الموقع بلا زيارات = صفر طلبات. خصّص:
- **بداية:** 1,000–2,000 ر.س/شهر (إعلانات جوجل بحث محلي + سناب/تيك توك).
- **بعد إثبات الجدوى:** 3,000–8,000 ر.س/شهر.

### 3.4 اقتصاديات الوحدة — احسبها قبل الإنفاق
```
تكلفة الطلب المحتمل (CPL)      = مصروف الإعلان ÷ عدد الطلبات
تكلفة الاكتساب (CAC)           = CPL ÷ نسبة تحويل الطلب إلى تفعيل
صافي الربح لكل عميل            = عمولة زين لكل تفعيل − CAC
```
**مثال عملي:**
- أنفقت 2,000 ر.س → وصلك 100 طلب ⇒ CPL = 20 ر.س
- 35% منها تحوّلت إلى تفعيل ⇒ 35 تفعيلاً ⇒ CAC = 57 ر.س
- عمولتك 70 ر.س للتفعيل ⇒ الربح = 35 × (70 − 57) = **455 ر.س**

الهامش ضعيف. الرافعات الثلاث لتحسينه:
1. رفع نسبة التحويل (سرعة الرد على واتساب أهم عامل — الرد خلال 5 دقائق يضاعف التحويل).
2. رفع قيمة العميل: بيع إضافي (جهاز، إكسسوار، ترقية باقة) ورسوم تجديد متكررة.
3. خفض CPL عبر القنوات المجانية: خرائط جوجل والسيو المحلي والإحالات.

### 3.5 نقطة التعادل
```
نقطة التعادل (تفعيلات/شهر) = (التكلفة الشهرية الثابتة + ميزانية الإعلان) ÷ صافي الربح لكل تفعيل
```
مثال: (100 ثابت + 2,000 إعلان) ÷ 13 ≈ **162 تفعيلاً شهرياً** لمجرد التعادل بهذه الأرقام.
هذا يوضح أن الموقع مجدٍ فقط إذا كان الاعتماد الأكبر على القنوات المجانية، أو إذا ارتفعت العمولة/البيع الإضافي.

## 5) قائمة تحقق قبل الإطلاق

- [ ] الموقع يفتح خلال أقل من 3 ثوانٍ على شبكة الجوال
- [ ] كل شيء يعمل على الجوال (80%+ من الزوار)
- [ ] زر واتساب ظاهر دون تمرير
- [ ] تنويه "لسنا الموقع الرسمي لشركة زين" واضح
- [ ] لا يوجد أي طلب لصورة الهوية أو بيانات حساسة
- [ ] خانة الموافقة على التواصل موجودة
- [ ] صفحة الخصوصية والشروط منشورة
- [ ] بيانات السجل التجاري ووسيلة التواصل معروضة
- [ ] SSL مفعّل (https)
- [ ] GA4 يسجّل نقرات واتساب كتحويل
- [ ] Google Business Profile مفعّل وموثّق
- [ ] الأسعار مذكورة كـ"استرشادية وفق تعرفة زين المعلنة"

## 6) الأخطاء الشائعة

1. إنفاق 20,000 ريال على موقع فاخر قبل التأكد من وجود طلب — ابدأ بـ 500 ريال واختبر.
2. إهمال خرائط جوجل مع التركيز على الموقع — العكس هو الصحيح للمندوب المحلي.
3. تأخر الرد على واتساب — أكبر مسرّب للطلبات.
4. نسخ أسعار زين الرسمية دون تنويه بقابليتها للتغيير — يسبب نزاعات.
5. استخدام شعار زين بلا إذن.
6. عدم قياس CPL — فتنفق شهوراً دون معرفة الجدوى.
